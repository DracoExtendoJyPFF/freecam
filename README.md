# Berry Avenue style freecam

A lightweight Roblox freecam script designed for Delta executor usage. It gives you smooth mouse rotation, responsive movement, and a clean freecam feel inspired by Berry Avenue-style camera control.

## Controls
- Toggle freecam: RightShift or F3
- Move: W, A, S, D
- Ascend: Space
- Descend: LeftControl
- Sprint: LeftShift
- Look around: mouse movement

## Notes
- This script uses `CameraType = Scriptable` while freecam is active.
- It keeps smooth camera motion instead of snapping instantly.
- Paste the script directly into your executor and run it.

## Script file
- `freecam.lua`
