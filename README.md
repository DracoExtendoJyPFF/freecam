# Berry Avenue style freecam

This repo contains a smooth Roblox freecam setup designed to feel close to a Berry Avenue-style camera.

## Files
- `freecam.lua` — original version
- `freecam_smooth.lua` — smoother, more polished camera movement

## Controls
- Toggle freecam: `RightShift` or `F3`
- Move: `W A S D`
- Ascend: `Space`
- Descend: `LeftControl`
- Sprint: `LeftShift`
- Look around: mouse movement

## Usage
Paste the script you want into your Delta executor and run it.

## Recommended use
`freecam_smooth.lua` is the better version if you want the cleanest smooth rotation and camera feel.
